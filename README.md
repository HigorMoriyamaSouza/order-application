# Order Application

Backend REST API for managing order data with authentication and persistent storage.

## Overview

Order Application is a backend project developed with JavaScript and Node.js. It provides RESTful operations for complete order management and uses MySQL for data persistence.

The project also includes JWT-based user authentication and Postman documentation covering the available API operations.

## Main Features

- Create order records
- Retrieve order records
- Update existing orders
- Delete orders
- Authenticate users with JSON Web Tokens
- Persist application data in MySQL
- Organize backend responsibilities in a modular structure
- Document API usage with Postman

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/HigorMoriyamaSouza/order-application.git
cd order-application
```

Install the project dependencies:

```bash
npm install
```

Configure the MySQL connection and authentication secrets required by the application.

The exact environment-variable names and execution command should be taken from the current project configuration and `package.json`.
